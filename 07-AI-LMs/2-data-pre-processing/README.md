# Data Pre-Processing

## What are we trying to accomplish?

By learning about data preprocessing and focusing on topics like understanding different types of data, installing and using Pandas, handling null values, standardizing and scaling data, and creating test and training splits, you are equipping yourself with the essential skills to prepare raw data for use in PyTorch neural networks. This process is crucial because the quality and format of input data directly impact the performance and accuracy of a neural network. By mastering these preprocessing steps, you'll ensure that your data is clean, consistent, and optimally structured for training effective machine learning models.
