# Intro to LM's

## What are we trying to accomplish?

By learning how to set up a Python environment with virtual environments (venvs), installing and running Jupyter Notebooks in VSCode, and installing PyTorch, you are establishing a solid foundation for developing and experimenting with neural networks in an efficient and organized manner. Understanding tensors, their operations, and built-in methods is crucial because tensors are the core data structures in neural networks, used to represent inputs, weights, and outputs. Mastering these concepts allows you to manipulate data effectively within PyTorch, facilitating the development of sophisticated models for tasks like binary and multi-class classification.
