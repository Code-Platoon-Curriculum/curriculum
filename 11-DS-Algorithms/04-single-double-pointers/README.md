# Single and Double Pointers

## What are we trying to accomplish?

In this lesson, we explore two fundamental algorithmic techniques: single pointer and double pointer traversal. Through practical examples, we'll learn how these techniques can be used to solve various problems efficiently. You'll learn these techniques and recognize when to apply them in the real world or on coding problems in an interview.

## TLO's (Tangible Learning Objectives)

- None of these concepts will be evaluated here in Code Platoon but they will be expected of you upon reaching the interview process or possibly your first job.

## ELO's (Enduring Learning Objectives)

- Implement algorithms that use a single pointer to traverse data structures.
- Implement algorithms using double pointers.
- Differentiate between single and double pointer approaches.
- Identify when to use single or double pointers for a problem.
