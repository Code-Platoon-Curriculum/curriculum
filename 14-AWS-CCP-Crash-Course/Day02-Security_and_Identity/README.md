# Security, Identity & Compliance

---

Security is a core tenant of AWS — and it's also one of the **heaviest weighted areas** on the CLF-C02 exam. Today's lessons introduce how AWS handles security **of the cloud** and how customers are responsible for securing their own usage **in the cloud**.

We’ll focus on how to control access with **IAM**, how to use tools like **MFA**, and how to secure your AWS environment using services like **AWS Shield**, **WAF**, **GuardDuty**, **Macie**, and **Inspector**. We'll also dive into governance tools like **CloudTrail**, **Config**, and **AWS Organizations**.

This is a high-value day for exam points — so pay close attention to exam-style phrases and how AWS names its security services.

---

## Learning Objectives

- Understand the Shared Responsibility Model and AWS security principles
- Identify the purpose of IAM users, groups, roles, and policies
- Describe when and why to use MFA and the IAM Identity Center (SSO)
- Recognize AWS tools for threat detection and security auditing
- Describe the function of CloudTrail, AWS Config, and AWS Organizations
