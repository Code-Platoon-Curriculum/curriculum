# Core AWS Services, Pricing & Support

---

Today’s focus is split between understanding **core AWS services** (the tech) and **how AWS charges for them** (the business). This is foundational for exam success — many CLF-C02 questions ask “Which pricing model is most cost-effective?” or “Which support plan includes a Technical Account Manager?”

We’ll review core AWS services like EC2, Lambda, S3, EBS, and RDS — just enough to describe their purpose and use cases — then dive into pricing tools like the AWS Calculator, Cost Explorer, and Billing Alerts. We’ll wrap with AWS support plans and how to avoid surprise bills.

---

## Learning Objectives

- Recognize core AWS services by category and description
- Identify the pricing models for EC2, S3, and Lambda
- Understand the difference between On-Demand, Reserved, and Spot pricing
- Use AWS budgeting tools like Cost Explorer, Budgets, and Pricing Calculator
- Understand the four AWS Support Plans and who they are for
