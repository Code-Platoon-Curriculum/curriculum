# Docker Compose

## What are we Trying to Accomplish?

In this lesson, we'll explore how to orchestrate multiple services using Docker Compose. You'll learn how to create a docker-compose.yml file to define and manage a multi-container application that includes Nginx, Gunicorn, React, Django, and PostgreSQL. By the end of this lesson, you'll be able to run an entire stack with a single command, streamlining your development and deployment processes.

## TLO's(Terminal Learning Objectives)

* __Understand Docker Compose__: Gain a solid understanding of what Docker Compose is and how it simplifies managing multi-container applications.
* __Create a docker-compose.yml file__: Learn how to define services, networks, and volumes for a full-stack application in a single YAML file.
* __Manage Multi-Container Applications__: Use Docker Compose to build, configure, and run a multi-container application with various services.
* __Deploy with Docker Compose__: Seamlessly deploy an integrated stack using Docker Compose to handle service dependencies and orchestration.

## ELO's(Enabling Learning Objectives)

* __Service Definition__: Define and configure services in a docker-compose.yml file, including React, Django, Gunicorn, PostgreSQL, and Nginx.
* __Networking in Docker Compose__: Understand how Docker Compose handles networking between containers and how to configure service communication.
* __Data Persistence__: Configure volumes in Docker Compose to ensure data persistence for your database and other services.
* __Managing Services__: Start, stop, and manage services using Docker Compose commands, including docker-compose up and docker-compose down.
