# PostgreSQL and Docker

## What are we Trying to Accomplish?

The goal of this Docker lesson is to demonstrate how to deploy a PostgreSQL database in a Docker container to ensure a consistent and portable environment. By using Docker, we aim to simplify the database management process, enhance scalability, and eliminate compatibility issues across different systems. This approach streamlines versioning and deployment, making it easier to manage updates and rollbacks while focusing on development and maintenance tasks.

## TLO's(Terminal Learning Objectives)

* **Create a Dockerfile**: Define the configuration for the PostgreSQL container, including environment variables and settings.

* **Build a Docker Image**: Generate an image from the Dockerfile that encapsulates the PostgreSQL setup.

* **Run a Docker Container**: Launch a container from the image, mapping ports for database access and enabling administrative rights.

## ELO's(Enabling Learning Objectives)

* **Understand Docker Basics**: Learn about Dockerfiles, images, and containers, including their roles and functionalities.

* **Manage Containers**: Use basic Docker commands to handle containers effectively, including starting, stopping, and inspecting them.
