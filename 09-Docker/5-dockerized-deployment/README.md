# Docker Hub

## What are we Trying to Accomplish?

In this module, we aim to understand the fundamentals of Docker Hub, including its purpose, how to use it to manage Docker images, and how to deploy these images to an AWS EC2 instance. By the end of this module, you should be able to effectively use Docker Hub for container management and understand the steps necessary to deploy your containers on a cloud platform.

## TLO's(Terminal Learning Objectives)

* __Understand Docker Hub__: Understand the purpose and functionality of Docker Hub.
* __Push Docker Images to Docker Hub__: Learn how to push Docker images to Docker Hub.
* __Deploy Docker Containers to an AWS EC2 instance__: Gain the skills to deploy Docker containers from Docker Hub to an AWS EC2 instance.  

## ELO's(Enabling Learning Objectives)

* __Container Management__: Explain what Docker Hub is and its role in container management.
* __Creating images__: Demonstrate how to create images that are then pushed to Docker Hub.
* __Pulling images__: Illustrate how to configure an AWS EC2 instance to pull and run a Docker container from Docker Hub.
