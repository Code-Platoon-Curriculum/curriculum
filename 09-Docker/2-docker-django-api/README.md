## TLO's(Terminal Learning Objectives)

- **Create a Dockerfile**: Define the configuration of the Django application container.
- **Build a Docker image**: Generate an image from the Dockerfile that encapsulates the Django setup.
- **Set up a PostgreSQL database container**: Make a PostgresSLQL container and connect it to the Django API container.

## ELO's(Enabling Learning Objectives)
- **Basic Docker Commands**: Use basic Docker commands to manage containers effectively.
- **Deploy and run the Django API project**: Deploy the Django API project connected to the PostgreSQL database using Docker.
