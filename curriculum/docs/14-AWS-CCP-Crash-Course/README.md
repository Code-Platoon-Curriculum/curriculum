## What are we trying to accomplish?

---

You’ve spent the last four weeks gaining real experience with cloud deployments, DevOps tools, and AWS services like EC2, S3, IAM, and Docker. But the **AWS Cloud Practitioner exam (CLF-C02)** isn’t focused on building — it’s focused on **understanding**.

This week, our goal is to shift from hands-on engineering to **exam mindset**.

You’ll learn how AWS wants you to think: how they categorize services, define the cloud, organize security models, and explain pricing. Our strategy is to **fail fast** on early practice exams, build familiarity with AWS vocabulary and patterns, and lock in high-level knowledge needed to pass the cert.

## Learning Objectives

---

- Understand the **structure and strategy** of the CLF-C02 exam
- Identify the **core categories of AWS services**
- Recognize **security responsibilities and IAM practices**
- Learn how AWS **prices and supports** its services
- Apply the **Well-Architected Framework** to scenario questions
- Gain confidence through repeated **full-length exam attempts**

## Module Topics

---

### Key Topics Covered

- **Cloud Concepts**

  - On-demand, elasticity, and scalability
  - IaaS, PaaS, SaaS
  - Regions, Availability Zones, Edge Locations
  - Cloud benefits (Agility, OpEx, Global Reach)

- **Security & Compliance**

  - IAM users, groups, roles, and policies
  - MFA, Shared Responsibility Model
  - AWS Shield, WAF, GuardDuty, Macie, Inspector
  - AWS Organizations and consolidated billing

- **Core Services & Pricing**

  - EC2 vs Lambda, S3, EBS, RDS, DynamoDB
  - Billing tools: Budgets, Cost Explorer, Pricing Calculator
  - AWS Support Plans: Basic, Dev, Business, Enterprise
  - TCO, CapEx vs OpEx

- **Well-Architected Framework**
  - 6 Pillars: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability
  - AWS Trusted Advisor and Well-Architected Tool
  - Disaster recovery models: Backup & Restore, Pilot Light, Warm Standby, Multi-site
