# Well-Architected Framework & Exam Strategy

---

Today is our final prep day — and it’s all about **putting the pieces together**. We’ll explore the AWS **Well-Architected Framework**, which shows up in multiple exam scenarios, especially around best practices, cost, performance, and resilience.

We'll also break down **disaster recovery models**, clarify what each of the six pillars means (and which AWS services map to each), and review everything we've learned this week.

Finally, you’ll take your **last full-length practice exam** — this time with confidence and a clearer understanding of how AWS thinks.

---

## Learning Objectives

- Describe the purpose of the AWS Well-Architected Framework
- Identify the six pillars and key tradeoffs for each
- Understand cost optimization and sustainability best practices
- Choose appropriate disaster recovery strategies (e.g. Pilot Light vs Multi-Site)
- Build a final exam mindset and strategy for success on the CLF-C02
