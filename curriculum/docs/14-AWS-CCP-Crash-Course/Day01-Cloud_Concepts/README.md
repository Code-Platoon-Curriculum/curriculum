# Cloud Concepts & AWS Global Infrastructure

Understanding how the AWS cloud is structured — and how it works differently than traditional on-prem systems — is essential to success on the AWS Cloud Practitioner (CLF-C02) exam. Today we’ll clarify foundational concepts like elasticity, regions, and IaaS vs PaaS, and help you build exam-level fluency with the language of cloud computing.

> Remember: You don’t need to *build* these architectures for the exam — you need to know how to *describe* them and pick the right service or strategy from a list.

---

## Learning Objectives

- Define basic AWS cloud terminology (on-demand, elasticity, scalability, etc.)
- Differentiate between IaaS, PaaS, SaaS and Cloud Deployment Models
- Identify components of the AWS Global Infrastructure
- Recognize business benefits of cloud computing
- Build familiarity with AWS conceptual language through your first practice exam
