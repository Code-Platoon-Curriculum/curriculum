# Customizing Your Shell with Oh-My-Zsh: Color Schemes and Powerline

## What are we trying to accomplish?

By customizing your shell with themes, color schemes, and Powerline fonts, you'll create a more user-friendly and informative terminal environment. A well-designed prompt can display crucial information at a glance, help you navigate directories more efficiently, and make your overall terminal experience more productive and enjoyable.

## Lectures and Assignments

- [Customize your shell & command line](./shell-customization.md)

## TLO's (Terminal Learning Objectives)

- Customize the appearance of your terminal with Oh-My-Zsh themes
- Configure your command prompt with informative elements
- Install and use Powerline fonts for advanced shell customization
- Edit your `.zshrc` file to apply shell customizations

## ELO's (Enabling Learning Objectives)

- Understand how Oh-My-Zsh themes work
- Configure and customize themes using theme options
- Understand the components of a shell prompt
