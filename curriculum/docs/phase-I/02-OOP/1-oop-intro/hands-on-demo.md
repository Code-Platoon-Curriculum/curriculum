## Ninja Coders
#### Hands on Demo

To make these concepts feel more tangible, we’ve built a small interactive game that allows you to work with objects and methods in real time.
> **Note:** This demo uses JavaScript instead of Python. The core concepts are the same—classes, attributes, and methods—but JavaScript requires the `new` keyword when creating an instance:

```javascript
john = new Person("John", 22)
```

- **Visit this Demo** 
  [https://code-platoon-assignments.github.io/Ninja-Coders/](https://code-platoon-assignments.github.io/Ninja-Coders/)
- **Open DevTools** 
  Press ++f12++ or right click and select `inspect`
- **Open JavaScript Console** 
  In the DevTools click the `Console` tab
- **Start Tutorial** 
  Type `tutorial()` and press ++enter++
  
As you progress through the tutorial, focus on how objects are created and how their properties and methods are accessed. These patterns directly translate to how you will use getters and setters in Python.
