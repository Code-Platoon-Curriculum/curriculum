## Keyboard Shortcuts

Download the cheatsheet for your OS and keep it open on your computer: 

- [VS Code Keyboard Shortcuts Cheatsheet Windows](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf)
- [VS Code Keyboard Shortcuts Cheatsheet Mac](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-macos.pdf)

The most useful keyboard shortcuts ones are:
 - `CMD /` - toggle commenting/uncommenting a line of code or highlighted code block
 - `CMD SHIFT p` - VS Code “Command Palette”
 - CMD ` - Hide/show Terminal
 - `CMD p` - Quick jump to a specific file
 - `CMD f` - Find in File
 - `CMD SHIFT f` - Find in All Files in Workspace
 - `CMD b` - Hide Show Explorer Sidebar
 - `ALT click` (hold down ALT and do a mouse click) - [Multiple Cursor Select](https://code.visualstudio.com/docs/editing/codebasics#_multiple-selections-multicursor)

 > For Windows/WSL replace `CMD` with `CTRL`
