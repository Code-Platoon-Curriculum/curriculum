Students will:
- Install and verify Docker on their local machine
- Write and build a basic Dockerfile
- Run containers from custom images
- Copy files into containers and read their contents
- Use `docker exec` to interact with running containers
- Bind local directories to containers for live file updates
- Create a shell script to automate the Docker build/run workflow

Assignments are designed to reinforce:
- Conceptual understanding
- Command-line fluency
- Real-world development practices
