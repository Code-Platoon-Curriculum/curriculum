# Assignments

Assignments should be completed from top to bottom as they will raise in difficulty the lower in the stack.

## Part I

- **Edge Functions Everywhere:** Use Claude Code to get a few edge functions in your application moving at minimum:
    - function that will return `{"message":"Hello World"}
    - function that accepts two numeric parameters (6, 6) and returns their multiplicative value in `{"result":36}

## Part II

- **Integrating APIs**: Integrate some API's to your applications and get a feel for the power of Edge Functions. At minimum:
    - Integrate the PokeAPI
    - Integrate an API that requires a secret key
