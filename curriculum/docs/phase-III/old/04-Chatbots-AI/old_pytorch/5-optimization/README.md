# Optimization - Improving the Learning Loop

## What are we trying to accomplish?

In this lecture, we will explore techniques to optimize  our model's training loop. We'll discover new activation functions and add more layer, incorporate dropout, and learn about early stopping. These are fundamental techniques that can improve how well our models learn.
