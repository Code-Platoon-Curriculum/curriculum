# Agents as Tools

## What you will Learn

In this module you will build the foundation for everything that follows: a working mental model of how large language models think, and the practical ability to direct one as a coding agent. You will start with the internals — how LLMs generate responses, why prompts succeed or fail, and what distinguishes a coding agent from the model it contains. Then you will install and configure Claude Code, develop cost-aware habits for model selection, and apply context management techniques that make Claude a precise collaborator on a real project rather than a generic text generator. By the end of this module you will be ready to use Claude Code deliberately — controlling what it knows, what it can access, and how it behaves within any project you give it.

## Lessons

- [Lesson 1 - Working with LLMs](./1-working-w-llms/README.md): Build a working mental model of how large language models function, then develop the prompt engineering skills to communicate with them reliably.
- [Lesson 2 - Coding Assistants](./2-coding-assistants/README.md): Understand the architecture of a coding agent — the orchestration loop, tools, and MCP — and configure Claude Code as a cost-aware coding assistant.
- [Lesson 3 - Claude in Action](./3-claude-in-action/README.md): Apply context management, MCP servers, custom commands, lifecycle hooks, and SDK integration to direct Claude Code precisely on a real Markdown-based project.
