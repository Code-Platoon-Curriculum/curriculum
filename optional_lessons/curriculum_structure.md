# Curriculum Structure & How to Navigate

## Lectures and Notes
- Lecture notes and code demos are stored in the **Avenger Demos and Notes** repository and are updated regularly:  
  [https://github.com/Code-Platoon-Curriculum/avenger_demos_and_notes](https://github.com/Code-Platoon-Curriculum/avenger_demos_and_notes)

## Assignments
There are two main ways to access assignments:

1. **Code Platoon Assignments repository:**  
   This repo contains all assignments but is currently not fully organized:  
   [https://github.com/orgs/Code-Platoon-Assignments/repositories](https://github.com/orgs/Code-Platoon-Assignments/repositories)

2. **Within the Curriculum repository by week and day:**  
   Navigate to the current week, then the directory numbered for the day of that week, and find the assignments that correspond to that day’s lectures.  
   [Curriculum Link](https://github.com/Code-Platoon-Curriculum/curriculum/tree/main)
   
   For example:  
   [Curriculum Example: Week 1, Day 4 - Python Pytest Intro](https://github.com/Code-Platoon-Curriculum/curriculum/tree/main/01-Js-Py-Intro/4-python-pytest-intro)
